# Study Helper

Exam prep and study support for New Zealand students. It starts with **Year 9 Mathematics & Statistics and Science** on the New Zealand Curriculum.

- **Learn**: short lessons and quick checks for every topic.
- **Practise**: adaptive practice marked instantly on the server, with hints and worked solutions. Maths has unlimited questions from templates whose answers are computed and checked by code.
- **Mock exams**: timed, exam-style papers across chosen topics, with grades and a per-topic breakdown.
- **Flashcards**: FSRS spaced repetition for key terms and formulas.
- **Study planner**: a day-by-day revision plan up to an exam, weighted towards weaker topics.
- **AI tutor**: Socratic help that gives hints and asks questions, never the answers to graded work. It also offers homework help from photos or PDFs, notes analysis and AI marking of written answers. Families bring their own Anthropic or OpenAI key.
- **Parent portal**: progress, activity, exam results, tutor chats, goals and rewards, and a weekly email.
- **Shared question bank**: questions generated by one family go into the shared bank, so nobody pays twice for the same question.
- **MCP server**: connect Claude, ChatGPT or Claude Code to the app (OAuth or personal tokens). Tools are scoped by role: student, parent or admin.

## Repository

```
apps/web/          React + Vite PWA (student app, parent portal, admin)
functions/         Firebase Cloud Functions (callables, AI, MCP + OAuth, scheduled jobs)
packages/shared/   Curriculum map, question schema, marking, maths templates, mastery, FSRS, planner, exams
content/           Lessons (Markdown), bank questions and flashcards (JSON)
tests/             Security-rules tests and backend integration tests (Firebase emulators)
scripts/           Dev helpers: emulators, seeding, content validation, set-admin
docs/              Plan, curriculum research, content guide, setup, security
```

## Quick start (local)

Requirements: Node 22, Java 21+ for the Firebase emulators (`scripts/with-java.mjs` finds one in `~/.jdks`), and the Firebase CLI.

```bash
npm install
npm run build -w functions        # functions must be built before the emulators load them
npm run emulators                 # auth, firestore, functions, storage, UI at http://localhost:4000
npm run seed:emulator             # in a second terminal: load content/questions into the emulator
npm run dev -w apps/web           # http://localhost:5173 (connects to the emulators automatically)
```

Or run everything at once with `npm run dev`.

## Tests

```bash
npm test                    # shared unit tests, including every maths template on 150 seeds
npm run test:rules          # Firestore + Storage security rules (emulator)
npm run test:integration    # end-to-end backend flows (emulator)
npm run validate:content    # schema, self-marking and coverage report for all content
npm run typecheck
```
