A **transformation** moves a shape to a new position. The starting shape is the **object** and the result is the **image**. If the object's corners are A, B and C, the image's corners are called A′, B′ and C′ ("A dash" or "A prime"). In this lesson you'll translate, reflect and rotate shapes on a coordinate grid. These three transformations never change a shape's size or shape, so the image is always **congruent** to the object.

## Translation

A **translation** slides every point the same distance in the same direction, with no turning or flipping.

A translation can be written as a column **vector**:

$$\begin{pmatrix} 3 \\ -2 \end{pmatrix}$$

The **top** number is the move in the $x$ direction (positive = right, negative = left). The **bottom** number is the move in the $y$ direction (positive = up, negative = down). So this vector means 3 right and 2 down.

### Example

A(1, 4) is translated by $\begin{pmatrix} 3 \\ -2 \end{pmatrix}$. A′ $= (1 + 3,\ 4 - 2) = (4, 2)$.

To find the vector from an object and its image, pick one corner and count how far it moves: across first, then up or down.

```check

  "options": [
    { "id": "a", "text": "$(2, 2)$" },
    { "id": "b", "text": "$(-6, 8)$" },

    { "id": "d", "text": "$(2, 8)$" }
```

## Reflection

A **reflection** flips a shape over a **mirror line**. Each point on the image is the **same distance** from the mirror line as the original point, but on the other side, measured at right angles to the line. A reflection reverses the shape, like your face in a mirror.

| Mirror line | What happens | Example |
|---|---|---|
| $x$-axis | $x$ stays, $y$ changes sign | (3, 2) → (3, −2) |
| $y$-axis | $y$ stays, $x$ changes sign | (3, 2) → (−3, 2) |
| $x = a$ (vertical line) | $y$ stays; count across to the line and the same again | in $x = 1$: (4, 2) → (−2, 2) |
| $y = b$ (horizontal line) | $x$ stays; count up or down to the line and the same again | in $y = -1$: (2, 3) → (2, −5) |

> **Watch out:** The $x$-axis is the **horizontal** axis, and its equation is $y = 0$. Reflecting in the $x$-axis changes the **$y$**-coordinate.

```check
{
  "type": "mcq",
  "prompt": "Point $Q(5, -1)$ is reflected in the line $x = 2$. Where is $Q'$?",
  "options": [
    { "id": "a", "text": "$(-1, -1)$" },
    { "id": "b", "text": "$(-5, -1)$" },
    { "id": "c", "text": "$(5, 5)$" },
    { "id": "d", "text": "$(9, -1)$" }
  ],
  "correct": "a",
  "feedback": {
    "b": "This is a reflection in the $y$-axis ($x = 0$), not in $x = 2$.",
    "c": "The mirror line $x = 2$ is vertical, so the $y$-coordinate does not change.",
    "d": "Q is 3 units right of the line, so its image is 3 units **left** of the line."
  },
  "solution": "Q is $5 - 2 = 3$ units right of $x = 2$. The image is 3 units left of it, at $x = 2 - 3 = -1$. The $y$-coordinate stays $-1$. So $Q' = (-1, -1)$."
}
```

## Rotation

A **rotation** turns a shape about a fixed point called the **centre of rotation**. To describe one, give the angle and direction. In Year 9 the angle is a multiple of 90°.

Rules for rotating about the origin $(0, 0)$:

| Rotation | $(x, y)$ becomes | Example: (4, 1) → |
|---|---|---|
| 90° clockwise | $(y, -x)$ | (1, −4) |
| 90° anticlockwise | $(-y, x)$ | (−1, 4) |
| 180° (either way) | $(-x, -y)$ | (−4, −1) |

You can always check with **tracing paper**: trace the shape and the axes, put your pencil on the centre, and turn the paper a quarter turn (90°) or a half turn (180°).

For a centre that isn't the origin, find how far the point is from the centre (across and up), rotate that, then add the centre back on.

### Example

Rotate A(3, 2) 90° anticlockwise about the origin: $(-y, x) = (-2, 3)$. The point moves from the first quadrant to the second quadrant, which is a quarter turn anticlockwise.

## Describing a transformation fully

Exam questions often ask you to "describe fully the single transformation". You must include every detail:

| Transformation | You must give |
|---|---|
| Translation | the vector, e.g. $\begin{pmatrix} -3 \\ 4 \end{pmatrix}$ |
| Reflection | the equation of the mirror line, e.g. $y = 2$ |
| Rotation | the centre, the angle, and the direction, e.g. 90° clockwise about (1, 0) |

## Exam tips

- Label image points with a dash: A → A′.
- Translation: top of the vector is left/right, bottom is up/down.
- Reflection: measure to the mirror line at right angles and go the same distance beyond it.
- Rotation: say clockwise or anticlockwise, and always give the centre.
- Check the image is the same size and shape as the object. If it isn't, something has gone wrong.
