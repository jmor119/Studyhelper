Patterns are everywhere: seats in rows, fence posts, the cost of a taxi ride. If a pattern grows by the same amount each time, you can write a rule for it and use it to predict any term, even the 100th, without drawing them all.

## Sequences and terms

A **sequence** is a list of numbers that follows a **pattern**. Each number in it is a **term**, and its **position** tells you where it is: 1st, 2nd, 3rd and so on.

In the sequence $5, 8, 11, 14, \ldots$ the 1st term is 5 and the 4th term is 14.

The difference between neighbouring terms is $8 - 5 = 3$, $11 - 8 = 3$, $14 - 11 = 3$. When the difference is always the same, it is called the **constant difference**, and the pattern is **linear**.

There are two kinds of **rule**:

- A **term-to-term** rule tells you how to get the next term: "add 3".
- A **position-to-term** rule tells you how to get any term straight from its position $n$: here it is $3n + 2$.

The position-to-term rule is much more powerful. To find the 100th term, substitute $n = 100$: $3 \times 100 + 2 = 302$.

> **Watch out:** a decreasing sequence such as $20, 17, 14, \ldots$ has a negative constant difference, $-3$.

## Finding the rule

1. Find the constant difference. The rule starts with (difference) $\times\, n$.
2. Compare that with the actual terms to see what to add or subtract.
3. Check the rule with another term.

### Example

Find the rule for $5, 8, 11, 14, \ldots$

| Position $n$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| $3n$ | 3 | 6 | 9 | 12 |
| Term | 5 | 8 | 11 | 14 |

Each term is 2 more than $3n$, so the rule is $3n + 2$. Check: when $n = 4$, $3 \times 4 + 2 = 14$ ✓

### Example: a decreasing sequence

Find the rule for $20, 17, 14, 11, \ldots$

The difference is $-3$, so start with $-3n$. When $n = 1$, $-3n = -3$, but the term is 20. That is 23 more, so the rule is $-3n + 23$, usually written $23 - 3n$.

## Patterns in diagrams and graphs

Patterns often come from diagrams. Squares made from matchsticks use 4, 7, 10, … matches.

Each new square adds 3 matches (top, bottom and one side), so the rule starts with $3n$. The very first square needs one extra match to close it off, so the rule is $m = 3n + 1$.

Explaining **why** a rule works, using the diagram, is a great way to show you understand it.

If you plot position against term on a graph, a linear pattern gives points in a **straight line**. The bigger the constant difference, the steeper the line.

| Position | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Matches | 4 | 7 | 10 | 13 |

> **Tip:** Make a table from the diagram first. It's much easier to see the constant difference in a table.

## Using rules and testing conjectures

### Which term is it?

Which term of $5, 8, 11, 14, \ldots$ is 98? Solve $3n + 2 = 98$: $3n = 96$, so $n = 32$. It is the 32nd term.

### Is a number in the sequence?

Is 100 in the sequence? Solve $3n + 2 = 100$: $3n = 98$, so $n = 32.67\ldots$ Positions must be whole numbers, so 100 is **not** a term.

### Conjectures

A **conjecture** is a statement you think is true but haven't proved yet. You test it by trying examples.

- **One counterexample** is enough to show a conjecture is false.
- To show it is always true, explain using the rule. For example, every term of $2n + 1$ is odd, because $2n$ is always even and an even number plus 1 is odd.

## Exam tips

- **Make a table** of position and term, and write the differences underneath.
- **The difference goes in front of $n$.** Then adjust using the first term.
- **Always check your rule** with a term you didn't use to find it.
- **Positions are whole numbers.** If solving gives a decimal position, the number isn't in the sequence.
- **Explain with the diagram:** say what the $3n$ and the $+1$ represent.
