Patterns are everywhere: chairs around tables, fence posts, savings that grow each week. In this lesson you will find the rule for a pattern, use it to predict, and plot patterns on a coordinate grid.

## The coordinate plane

A coordinate grid has two number lines: the **$x$-axis** goes across and the **$y$-axis** goes up. They cross at the **origin**, $(0, 0)$.

The axes carry on past 0 into negative numbers. That splits the grid into four **quadrants**, numbered anticlockwise from the top right.

Each point has **coordinates** written as an **ordered pair** $(x, y)$. The $x$-coordinate comes first: how far right (positive) or left (negative). The $y$-coordinate comes second: how far up (positive) or down (negative).

## Linear patterns

In a **linear pattern**, the terms go up (or down) by the same amount each time. That amount is the **constant difference**.

- $5, 8, 11, 14, \ldots$ goes up by 3 each time.
- $20, 16, 12, 8, \ldots$ goes down by 4 each time.
- $1, 2, 4, 8, \ldots$ is **not** linear. The jumps are 1, 2, 4, …, which are not the same.

Each number in a pattern is a **term**. Its **position** number tells you where it is: 1st, 2nd, 3rd, ….

## Finding the rule

A linear pattern follows a **rule** like $t = a \times n + d$, where $n$ is the position and $t$ is the term.

1. Find the constant difference. That's $a$, so the rule starts with $a \times n$.
2. Compare $a \times n$ with the real terms. Add or subtract to fix the difference. That's $d$.
3. Check the rule with another term.

### Example

For the matchsticks, the constant difference is 3, so start with $3n$.

When $n = 1$, $3n = 3$, but the term is 4. So add 1.

The rule is $t = 3n + 1$. In words: "multiply the position number by 3, then add 1".

Check with $n = 4$: $3 \times 4 + 1 = 13$ ✓

For a decreasing pattern like $20, 17, 14, \ldots$ the rule takes away: $t = 23 - 3n$.

A rule lets you **predict** terms far away. For $t = 3n + 1$, pattern 50 needs $3 \times 50 + 1 = 151$ matchsticks.

You can also test a **conjecture** (an idea you think might be true). Mia thinks 100 is in the pattern $t = 3n + 1$. Solve $3n + 1 = 100$: $3n = 99$, so $n = 33$. It's a whole number, so Mia is right: 100 is term 33.

Is 50 in the pattern? $3n + 1 = 50$ gives $3n = 49$. 49 isn't a multiple of 3, so 50 is not in the pattern.

## Putting it together

- Coordinates are $(x, y)$: across first, then up or down. Negative means left or down.
- The quadrants go anticlockwise: first (top right), second, third, fourth (bottom right).
- A linear pattern has a **constant difference**, and its graph is a straight line.
- The rule $t = a \times n + d$: $a$ is the constant difference, and $d$ fixes the first term.
- Always check your rule with a term from the pattern.
- To test whether a number is in a pattern, make an equation and see if $n$ is a whole number.
